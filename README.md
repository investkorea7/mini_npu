# Mini NPU Simulator 리포트

## 1. 실행 방법
본 프로그램은 파이썬 표준 라이브러리만을 활용하여 작성되었으며, 터미널에서 다음 명령어로 실행합니다.

python3 main.py

* **모드 1 선택 (1 입력)**: 3x3 필터 A, B 및 패턴 데이터를 직접 콘솔로 입력받아 연산 점수, 시간(ms), 판정 결과를 출력합니다.
* **모드 2 선택 (2 입력)**: 동일 디렉토리의 data.json 파일을 읽어와 크기별(5x5, 13x13, 25x25) 패턴을 일괄 분석하고 성능 표 및 결과 요약을 출력합니다.

## 2. 구현 요약

* **라벨 정규화 (Standardization)**: 입력 데이터나 Expected 값으로 전달되는 '+', 'cross', 'x' 등의 다양한 표현을 내부 표준 라벨인 Cross와 X로 통일하여 판정 로직의 일관성을 확보했습니다.
* **MAC (Multiply-Accumulate) 연산**: 외부 라이브러리(NumPy 등) 없이 순수 Python 이중 반복문(for)을 통해 패턴과 필터 간 위치별 곱셈 및 누적합을 구현했습니다.
* **동점 및 오차 처리 정책 (Epsilon)**: 부동소수점 연산 시 발생할 수 있는 미세한 오차를 고려하여 두 점수의 차이가 1e-9 미만일 경우 UNDECIDED(판정 불가)로 분류했습니다.
* **예외 처리 및 안정성**: 모드 1의 경우 사용자 잘못 입력 시 안내 문구 출력 후 재입력을 유도하며, 모드 2의 경우 스키마/크기 불일치가 발생해도 프로그램 중단 없이 해당 케이스만 FAIL 처리하도록 구성했습니다.

## 3. 결과 리포트

### (1) 실패 원인 분석 (FAIL 케이스 검증)
현재 검증용 데이터셋(data.json) 실행 결과 총 4개 테스트 중 4개 통과(FAIL 0개)를 기록했습니다. 
이번 테스트에서 실패 케이스가 발생하지 않은 원인은 다음과 같습니다. 첫째, 라벨 정규화 함수(normalize_label)를 통해 'x'와 '+' 같은 다양하게 표기된 입력값을 내부 표준 규격인 'X'와 'Cross'로 사전 처리했기 때문입니다. 둘째, 부동소수점 오차 완화를 위한 Epsilon 기반 비교 정책(1e-9)을 도입하여 수치 비교 시 발생할 수 있는 오판정 가능성을 사전에 차단했기 때문입니다. 만약 크기 불일치나 라벨 파싱 오류가 발생하더라도 프로그램 전체가 다운되지 않고 해당 케이스만 FAIL로 추적되도록 설계되었습니다.

### (2) 시간 복잡도 분석 (O(N^2))
성능 분석 결과, 패턴 및 필터의 가로/세로 크기 N이 커짐에 따라 연산 시간이 기하급수적으로 증가하는 경향을 확인할 수 있습니다. 
* 3x3 입력 (연산 횟수: 9회) -> 평균 연산 시간: 약 0.002 ms
* 5x5 입력 (연산 횟수: 25회) -> 평균 연산 시간: 약 0.012 ms
* 13x13 입력 (연산 횟수: 169회) -> 평균 연산 시간: 약 0.053 ms
* 25x25 입력 (연산 횟수: 625회) -> 평균 연산 시간: 약 0.183 ms

이러한 수치적 증가는 MAC 연산의 구조적 특징에 기인합니다. 2차원 N x N 데이터 구조에서 모든 위치의 값을 포개어 곱하고 더하기 위해 이중 반복문을 수행하므로, 전체 연산 횟수는 정확히 N x N = N^2번이 됩니다. 따라서 본 시뮬레이터의 시간 복잡도는 O(N^2)입니다. 이미지의 해상도나 패턴의 크기가 증가할수록 CPU 기반의 직렬 반복문 연산은 성능 한계에 직면하게 되며, 이것이 실제 AI 시스템에서 수천 개의 MAC 연산을 동시에 병렬로 처리하는 NPU(Neural Processing Unit) 하드웨어가 필요한 핵심 이유임을 알 수 있습니다.
